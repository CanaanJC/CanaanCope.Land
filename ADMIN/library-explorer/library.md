# Library Browser
- Click a library to open it, then click a folder to go deeper.
- Click a blog to open it directly in the editor.
- Click the **⋮** next to any folder or blog to Rename or Move it.
# Moving Items
- Click **Move** on an item's **⋮** menu — it gets flagged (highlighted gold).
- Navigate anywhere in the tree (even into a different library).
- Once you're standing in a *legal* destination, a **Move Here** button appears in the action bar.
- Blogs can only be moved into the deepest folder level of a library.
- Plain folders can only be moved anywhere ABOVE that deepest level.
- Click **Cancel Move** at any time to back out.
# New Folder
- Only available while inside a library, above its deepest folder level.
- Prompts for a name, creates it at your current location.
# New Library
- Prompts for a title, creates the library folder + libraries.json entry, depth defaults to 1 (editable later in the admin panel's Libraries element).
