# Library Types
## Date Sorted
- Blogs are sorted by the first date in their config
- Only works with `depth=1`
## File Sorted
- blogs are sorted by their folder name alpha numerically
- Any Library with a greater depth than 1 sorts the folders alpha numerically
    - Name these folders like this `X_NAME` 
    - Anything before the underscore inclusive will not be rendered in the drop downs on the page
# Featured Blogs
- The first blogs are ones that don't have dates and are sorted alpha numerically
- After those, all dated blogs are sorted by their start date.
