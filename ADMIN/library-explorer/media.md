# Media Manager UI
- To move files just click and drag. 
- To Rename, Right Click.
# Link Embed Thumb Nail
- Any image inside your media folder that is named `thumb` will be used as the thumbnail. 
- If non is found it will fall back to the first image sorted alphanumerically. 
# Folders
- The Folder Thumbnail will render as the first image alphanumerically. And the rest of the images 
inside the folder will be shown in that order. 
- Id recommend naming your files with numbers at the start.
